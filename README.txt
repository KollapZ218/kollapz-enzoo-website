Kostenlos veröffentlichen:
1. GitHub öffnen und ein neues Repository namens kollapz-enzoo-website erstellen.
2. index.html hochladen.
3. Repository > Settings > Pages.
4. Deploy from a branch auswählen, Branch main, Ordner /(root), Save.
5. Nach einigen Minuten zeigt GitHub die öffentliche URL.
